# Top Control Bar For AutoHotKey

#To use:

very simple to use
the only file you need is ```top bar.ahk```

download that file to some path ```C:\X\XX```

then, download AutoHotKey

you can download it via winget:

```winget install -e --id AutoHotKey.AutoHotKey```

once download finishes:

double click the file you downloaded to that path C:\X\XX 
(the top bar.ahk file)
open with AutoHotKey if prompted

It'll run at the top. in the system tray (taskbar arrow at the right side) you can right click the green H to check 'start with windows' or not.

that is all.

## key features:
- written in .ahk, and ultra-light-weight (file size is around
- very fast and code is very changeable
- all windows behaviour works around it.
- music marquee works with all languages.
- easily customisable (change in font, background color, text colour, size, opacity, etc.)
- cpu, and ram util as percentages
- time in miliseconds (reprogrammed own clock to accommodate this)
- wifi settings redirects to windows wifi settings, volume slider also there.
- has single-monitor brightness alteration as a slider, and changes the brightness using the actual monitor firmware (the monitor button settings) ++ (supported by most monitors)
- can have date in different formats, change marquee speed, length, uses live temperature, has working system tray button (...), has locally rendered microsoft logo, rather than a bloating jpeg or png.
